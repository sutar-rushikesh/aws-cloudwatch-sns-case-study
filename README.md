# AWS CloudWatch + SNS Case Study – Monitoring and Alerting

## 📌 Case Study Overview

An organization wants to monitor EC2 instance performance and receive alerts when CPU utilization exceeds a defined threshold.
Additionally, automated action should be triggered to protect infrastructure from overload.

You are assigned to implement monitoring, alerting, and automated response using:

- Amazon CloudWatch
- Amazon SNS
- EC2 Monitoring

---

## 🎯 Objectives

- Create SNS Topic and Subscription
- Create CloudWatch Dashboard
- Monitor EC2 CPU utilization
- Create CloudWatch Alarm
- Trigger SNS email notification
- Perform automated EC2 action when threshold is exceeded

---

## 🧩 Tasks

1. Launch an EC2 instance
2. Create SNS Topic
3. Create Email Subscription and confirm it
4. Create CloudWatch Dashboard
5. Add EC2 CPU Utilization Metric
6. Create CloudWatch Alarm
7. Configure threshold >= 60%
8. Configure SNS notification
9. Configure EC2 Stop action
10. Generate CPU load and observe alarm trigger
